# dev-expert

Development-policy package expert (`oats.dev`, repository `oats-dev`). Owns the FACTS of the OATS-project development package at each published version: the review discipline it ships and how it behaves in use. Package experts own their package's facts and nothing cross-package: cross-package provider-integration judgement is read from [integrations-expert](/nodes/integrations-expert/index.md), and cross-package architecture stays with [oats-expert](/nodes/oats-expert/index.md). Charter set by the 2026-09-24 [roster amendment](/nodes/oats-expert/decisions/roster-amendment-operator-and-integration-experts.md) and workspace model v2's rule that every package repository carries a member soul that is its expert ([workspace model v2](/nodes/oats-expert/decisions/workspace-model-v2.md), point 25).

**Chartered, not yet seeded (Phase D slice 3).** The owning soul is the package repository's member soul of the same name.
