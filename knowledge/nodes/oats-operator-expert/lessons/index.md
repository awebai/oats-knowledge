# Lessons

Placement, identity, verification and adoption judgement learned operating deployments.

* [Fresh machines do not reset account history](fresh-machines-do-not-reset-account-history.md) - First-time onboarding needs fresh service-account evidence as well as a fresh machine, followed by a second machine joining the same workspace, because existing accounts and single-machine trials hide different failures.
* [Intake consent does not predict auto-mode approval](intake-consent-does-not-predict-auto-mode-approval.md) - Onboarding handoffs need actual scoped consent on record, but neither that consent nor suppressing intake questions guarantees Claude Code will permit consequential setup steps.

* [Trial runtime redirection excludes host-service proof](trial-runtime-redirection-excludes-host-service-proof.md) - Linux trials reported excluded host-service access but surviving absolute temporary-file writes, so runtime redirection and a private temporary mount each prove only the boundary exercised.
* [Trial model identity needs launch enforcement and observation](trial-model-identity-needs-launch-enforcement.md) - A controlled Claude trial ran unintended models despite soul preferences, so a fixed-model comparison needs an enforced launch boundary and observed model identity for participating seats.
* [Trial stdin stalls are harness faults, not coordination outcomes](trial-stdin-stalls-are-harness-faults.md) - A Claude trial stalled on bare cat commands reading a socket that did not close, so background-task waiting and any reaper intervention must be separated from measured coordination behavior.
* [Seeded review needs planting and catch validation](seeded-review-needs-planting-and-catch-validation.md) - Post-authorship defect injection triggered tamper handling and cooperative planting varied between instances, so seeded-review comparisons need actual planted populations and validated catch stages rather than raw counts.
* [Rootless messaging needs the server's database extensions, not just PostgreSQL](rootless-messaging-needs-required-database-extensions.md) - A rootless aweb trial failed with the pgserver wheel because pgcrypto was absent and succeeded with a PostgreSQL 16 build including that extension.
* [Claude trial metrics need run, origin and message identity](claude-trial-metrics-need-origin-and-message-identity.md) - Claude trial measurements need run, origin and message identity, with per-command timing evidence retained before teardown rather than attributing whole-turn duration to component owners.
* [Knowledge onboarding must check package-soul launches](knowledge-onboarding-must-check-package-soul-launches.md) - A Claude-only trial launched its working souls successfully but refused harvesters until an explicit host launch preference was selected, so onboarding must check the knowledge-operation souls before the first checkpoint.
* [Check local knowledge bindings from a spawned home](check-local-knowledge-bindings-from-a-spawned-home.md) - An oats.okf 5.7.0 trial failed to read a local Git base through a file URL and recovered with a plain path after respawn, so binding acceptance must include a spawned-home read rather than a configuration edit alone.
* [Replace shared shell tools atomically](replace-shared-shell-tools-atomically.md) - A trial setup reportedly failed when its shared shell tool was rewritten during execution, so tool publication must preserve the bytes already-running readers use rather than mutate them in place.

* [Place each fact at the scope that owns it](place-each-fact-at-the-scope-that-owns-it.md) - Shared declarations, host facts or spawn: choose by how many holders the fact may have, meaning over type.
* [The installed provider is the authority for a setting](the-installed-provider-is-the-authority-for-a-setting.md) - The preview proves delivery, not effect; configure against what the locked provider reads.
* [Check the target provider's host requirements before sync](check-target-provider-host-requirements-before-sync.md) - Green checks against the current lock do not establish readiness for a moving provider; compare the target version's host requirements and satisfy them before writing the new lock.
* [The messaging root is a deployment-bounded host fact](messaging-root-placement-decides-the-team.md) - Where the root sits decides which team residents mint into; a root above the deployment is a silent cross-team leak.
* [Retire ordering for self-custodial identities](self-custodial-identity-retires-from-inside-the-home.md) - De-register from inside the home before removing it; a stranded record gets one deferred re-check.
* [A team-local identity is reachable only inside its team](a-team-local-identity-is-reachable-only-inside-its-team.md) - A seat other teams must contact needs a custody-served global identity, never a per-instance global mint.
* [Anything read through a shared checkout is only as current as that tree](shared-checkout-serves-a-stale-soul.md) - Validity is not currency; verify the tree against the remote and leave repair to its owner.
* [A shared checkout's local main leaks into every worktree spawned from it](a-shared-checkouts-local-main-leaks-into-every-spawned-worktree.md) - Branch from the remote main; commits a tree cannot push are stranded and ride every PR.
* [A channel's verified=false is the channel's verdict](a-channel-verification-flag-is-the-channels-verdict-not-the-senders.md) - Confirm with a CLI fetch and a registry lookup before asking the sender to rotate anything.
* [Tracker integrations are partial surfaces](tracker-integrations-are-partial-surfaces.md) - Tell an adopter up front what agents can operate in the tracker, what stays human-owned, and that gaps escalate.
