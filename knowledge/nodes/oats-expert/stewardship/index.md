# Stewardship

How the OATS project ships: judgement only, each concept with an owner and an
update-on-change rule; procedures live in the oats-expert soul's skills.

* [How the OATS project ships and reviews](review-protocol.md) - PRs judged by four gates against exact heads, fresh reviewers, tests that agree with the requirement, a second reader for a lone gate.
* [Release judgement for the tag-driven lane](release-traps.md) - Publish before housekeeping, never retag, verify the installed artifact, mirror and pin in one PR, name a pin's lag.
* [Cross-workstream delivery: freeze the contract first, adopt then adapt, prove the merge](multi-workstream-delivery.md) - Ship the frozen contract first, adopt sibling suites wholesale, prove auto-merges kept both deltas.
