# Rationale

The accepted positioning makes specialization a reviewed project artifact rather than a side effect of one conversation. A full instance can be steered, resumed and coordinated; it is not merely an anonymous workflow step. Native subagents remain useful, but do not by themselves supply this durable role continuity.

Curating a specialist's context is preferable to presenting every procedure and hoping the model ignores irrelevant ones. Runtime diversity should preserve native strengths, not flatten all sessions into a least-common-denominator workflow engine.

Continuity is an opportunity, not automatic learning. Souls carry identity and procedures; selected external knowledge supplies accepted judgment. A new instance becomes better informed only when useful evidence has been judged, delivered, accepted and read. No knowledge integration is compulsory, and managed context selection is not whole-harness isolation.
