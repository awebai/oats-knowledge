# Decisions

* [Durable specialization preserves judgment across sessions](durable-specialization.md) - Agent expertise is a versioned project artifact; durable specialist roles keep reviewed judgement without replacing native sessions.
* [The OATS soul roster: expert domains own knowledge nodes, developers own none](domain-expert-rebuild.md) - The one canonical roster: domain and package experts own nodes, developer and admin souls own none, release stewardship is a Playbook.
* [Optional reference theory, capability-owned runtime](optional-reference-theory.md) - OATS offers an adoptable reference knowledge theory while each capability owns its runtime and may choose another model.
* [External knowledge needs source-independent custody](external-knowledge-custody.md) - Knowledge custody is separate from source evidence and the work branch; proposals are not accepted knowledge.
* [Centralised per-soul knowledge is the default; capabilities own learning; instances are situated, not short](flexible-knowledge-and-situated-instances.md) - The default routes knowledge centrally per soul, capabilities own their learning model, and speciation follows evidence.
* [Official OATS development runs on the architecture it offers adopters](official-development-dogfoods-the-workspace.md) - The framework and its package repositories form one workspace under one stewardship gate; member and publisher roles never collapse.
* [A workspace definition, a source library and a capability package are different responsibilities](workspace-definition-is-not-a-package.md) - Composition, behaviour, transport and realisation are distinct responsibilities joined only by reciprocal membership; consuming is not joining.
* [Workspace model v2 — membership is trust, location is not version, every capability is copied whole into the instance](workspace-model-v2.md) - Reciprocal membership is the trust decision for members, packages are the only versioned source, and nothing is installed.
* [Operating OATS is capability content; the reviewed list is the marketplace](official-capabilities-and-reviewed-marketplace.md) - Operational knowledge ships as the official core and setup capabilities, and the reviewed catalog defines officialness.
* [Pre-adoption contracts are removed, not translated](clean-contract-precedent.md) - An unadopted shape is removed with a pointed error naming its replacement; published commitments keep reader compatibility.
* [New kernel lines roll out fresh-install-first; historical migration is deferred, never destructive](fresh-install-first-rollout.md) - Roll out by provisioning fresh deployments; park conversion without erasing or relabelling history.
* [Runtime, messaging and viewers have separate owners; a wake is a hint, not consumption](runtime-messaging-viewer-ownership.md) - The kernel owns execution, the messaging capability owns identity and delivery, and viewers are clients.
* [The served identity is a messaging-layer fact the kernel binds and shows, never kernel vocabulary](served-identity-is-a-messaging-layer-fact.md) - The identity choice travels in the provider payload with no spawn flags; the provider owns every identity rule.
* [Desktop parity: the design's semantics win where safe; where they imply authority OATS lacks, the UI tells the truth](desktop-parity-lifecycle-and-policy.md) - Remove retains work, Stop is recursive, rows render only kernel facts, child spawns are enforced, and the kernel's JSON is the Desktop's model.
* [A forge connection is a workstation fact, not a capability](forge-connection-is-a-workstation-fact.md) - Forge sign-in is a per-machine Desktop connection under the forge CLI's custody; automatic PR is ADE-owned.
* [Team as a first-class config entity](team-as-config-entity.md) - The classic-path team block and what survives of it: the instance name is the messaging alias.
