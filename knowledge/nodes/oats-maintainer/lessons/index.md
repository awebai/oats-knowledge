# Lessons

* [Adoption evidence and authority must match the claimed outcome](adoption-evidence-and-approved-scope.md) - Installation, execution, publication, consumption and learning are different evidence; classify a gap before adding anything.
* [Second-operator acceptance — what the gate is for, how to read its failures, and the contract-siblings rule](second-operator-acceptance.md) - An outsider on the published combination, verifying by positive enumeration, is the acceptance gate; four failure classes, four owners.
* [Review the whole PR merge range for scope, not only the intended feature files](pr-branch-merge-range-scope.md) - Unrelated local, stewardship or soul commits ride feature branches; list the merge range before running gates.
* [A commit cherry-picked across a base change must be re-read as a diff against the new base](a-cherry-pick-across-a-base-change-must-be-reread-as-a-diff-against-the-new-base.md) - A rebuilt branch can reintroduce text the new base removed; read the full three-dot diff, docs included.
* [A re-dated claim must be re-verified against the release it now names](a-re-dated-claim-must-be-re-verified-against-the-release-it-now-names.md) - A version bump inside a sentence that asserts behaviour is a fact to verify, never a mechanical edit.
* [Review a validator against every nullable field the wire spec names, and probe the binary with the null](review-a-validator-against-every-nullable-field-the-wire-spec-names.md) - Walk the spec's nullable fields and drive the binary with each null; the implementer's strict test proves the imagined shape.
* [Check the PR's own check before an ACK; the author's local run is not the runner's run](check-the-pr-check-not-only-the-authors-local-run.md) - Read the PR's check conclusion and failed log every round; a runner without host binaries is a different environment.
* [Report an outcome only from a read-back of the target](verify-the-remote-ref-after-every-scripted-push.md) - Heads, merges and tags are announced from a read-back in their own step, never from a chain's intent.
* [Search the whole repository before declaring a cited file missing](search-the-whole-repository-before-declaring-a-cited-file-missing.md) - Absence from one directory is not a history; search the tree and say where you looked.
* [A test harness must reproduce a known-good baseline before any delta it reports means anything](validate-the-harness-against-a-known-good-baseline.md) - Run the unmodified control in the new environment first and require it to match the trusted result.
