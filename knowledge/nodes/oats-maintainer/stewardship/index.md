# Stewardship

How the OATS project ships: judgement only, each concept with an owner and an
update-on-change rule; procedures live in the oats-expert soul's skills.

* [How the OATS project ships and reviews](review-protocol.md) - Maintainer review binds four gates to exact content, requires evidence for affected paths outside PR CI before hand-over, uses fresh and second readers, and judges tests against requirements rather than implementations.
* [Release judgement for the tag-driven lane](release-traps.md) - Release judgment distinguishes publication from artifact availability, rehearses changed upgrade paths from released state, and treats source, tag, mirror and every form of version pin as one coordinated change.
* [Cross-workstream delivery: freeze the contract first, adopt then adapt, prove the merge](multi-workstream-delivery.md) - Ship the frozen contract first, adopt sibling suites wholesale, prove auto-merges kept both deltas.
