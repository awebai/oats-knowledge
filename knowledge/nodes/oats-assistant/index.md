# oats-assistant

Persistent, deployment-owned onboarding expertise: practical judgement for helping people adopt and configure OATS, and for handing them to the right expert or canonical procedure. Procedures themselves live in skills and repository docs; this node holds the judgement the docs do not state.

## Sections

* [lessons](lessons/index.md) - Adoption and configuration judgement learned the hard way.

## Start here

* [Tracker integrations are partial surfaces; set expectations before adopting one](lessons/tracker-integrations-are-partial-surfaces.md) - A tasks-layer integration deliberately exposes only the issue-execution slice of a tracker, so an adopter must be told up front what agents can operate, what stays human/UI-only, and that unsupported operations escalate rather than improvise.
