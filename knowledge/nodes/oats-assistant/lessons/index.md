# Lessons

Hard-won onboarding and adoption judgement: what an assistant helping a deployment adopt or configure OATS should say and check before promising an outcome.

* [Tracker integrations are partial surfaces; set expectations before adopting one](tracker-integrations-are-partial-surfaces.md) - A tasks-layer integration deliberately exposes only the issue-execution slice of a tracker, so an adopter must be told up front what agents can operate, what stays human/UI-only, and that unsupported operations escalate rather than improvise.
