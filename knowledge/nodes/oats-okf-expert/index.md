# oats-okf-expert

Knowledge package expert (`oats.okf`, repository `oats-okf`; current release 4.0.3). Owns the FACTS of the knowledge provider at each published version: what its binding reads from the merged payload and the soul's knowledge declaration, how consultation serves accepted bases, how capture, the harvester and the maintainer behave and refuse, and how bases, bindings and node ownership behave in practice. The owning soul is the package repository's member soul of the same name. Cross-package provider-integration judgement is read from [integrations-expert](/nodes/integrations-expert/index.md); cross-package architecture stays with [oats-expert](/nodes/oats-expert/index.md). Charter: the [roster](/nodes/oats-expert/decisions/domain-expert-rebuild.md) and [workspace model v2](/nodes/oats-expert/decisions/workspace-model-v2.md) point 25.

**Seam:** the theory of what counts as knowledge (the two-part test, the reject list, promotion) lives in [oats-expert](/nodes/oats-expert/index.md) (see [optional reference theory](/nodes/oats-expert/decisions/optional-reference-theory.md)); this node records how the package implements and enforces it.
