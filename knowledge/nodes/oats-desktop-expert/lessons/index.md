# Lessons

Discoveries, integration limitations and verification judgment that the repository cannot express. Where a defect has since become a test, the lesson keeps the stance and names the elimination route.

* [Pending lifecycle state is not evidence of failure](pending-lifecycle-state-is-not-failure.md) - Require producer liveness to interpret held lifecycle rows, keep unknown retirement outcomes non-failing with secondary recovery, and reconcile each local apply only against a later covering observation.
* [Attribute spawn latency before choosing the component to fix](measure-spawn-latency-without-spawning.md) - Combine existing phase evidence with preview tracing, caller profiling and repeated read timings to assign spawn costs to their owners without creating an instance on the measured deployment.
* [xterm upgrades must revalidate private reads and copied behavior](xterm-internal-mirrors-upgrade-liability.md) - A major xterm upgrade can leave private reads and copied algorithms working syntactically but wrong semantically, so qualify those dependencies against the new version rather than trusting a green build.
* [A shard number does not identify the same tests after main moves](shard-membership-is-run-specific.md) - Before attributing a CI hang to a Desktop change, establish test membership in that exact run rather than treating absence from one shard's log as evidence of a hang.
* [Splitting an agreed rule across PRs also needs agreement](staging-an-agreed-rule-needs-agreement.md) - A Desktop implementation plan cannot silently narrow an agreed rule; obtain agreement on omitted cases before building a staged delivery and verify every included case through its actual defaults.
* [Tests of kernel text own the client's reading, not the kernel's sentences](kernel-text-tests-own-the-client-reading.md) - Test the client's handling of live producer text without freezing relations between kernel sentences, and derive forbidden-text checks from the producer rather than copied wording.
* [Nested deadlines must let the inner outcome reach the view](nested-deadlines-must-let-the-inner-outcome-arrive.md) - A view's promise to show a bounded kernel answer requires every enclosing wait to outlast the inner one, including intermediary proxy classes omitted by endpoint-only review.

* [Identity and relationships must stay legible under ambiguity](identity-and-relationship-legibility.md) - Key by qualified identity and resolve ambiguity over the full roster before filtering.
* [Keyboard policy follows actions and user intent](keyboard-focus-and-action-ownership.md) - Focus intent, effective bindings and event ownership must agree without consuming native terminal or control input.
* [GPU restart recovery follows the shared glyph atlas's scope](gpu-restart-recovery-follows-shared-atlas-scope.md) - Recover xterm's shared atlas across all live terminals in one debounced pass, because independent terminal clears can corrupt a resource shared by the window.
* [Async completion must still own the user's intent](asynchronous-intent-and-truthful-outcomes.md) - Background work preserves intent and separates creation, readiness and success; confirmations describe effect boundaries without suppressing unrelated reads or inventing stale-result state.
* [Prove coupled Desktop changes on main and on the prospective kernel merge](coupled-kernel-and-desktop-landings.md) - When a kernel change would make Desktop actively wrong, keep the Desktop delta reviewable on main but prove the combined tree before maintainers land the pair together.
* [Browser-owned state and accessibility under repaint](browser-owned-state-and-accessibility-under-repaint.md) - A live selection, open form or focused modal control is a repaint barrier; declared modality is not containment.
* [Accessibility is proven on effective colours, not token pairs](effective-contrast-over-token-pairs.md) - Contrast is checked on every colour the user actually sees, not on token pairs.
* [Verification judgment for Desktop's privileged surfaces](verification-judgment-for-privileged-surfaces.md) - Prove guards at real boundaries, include source-evaluating tests of main and renderer code, and contain native verification with enforced lifetime and output bounds rather than trusting test selection or a passing assertion.
* [macOS installers — what ad-hoc signing fixes and what it cannot](macos-adhoc-signing-decision.md) - Complete ad-hoc signing fixes "damaged" bundles; only Developer ID plus notarization removes the warning.
* [Terminal stroke-weight comparisons depend on polarity and platform](terminal-weight-polarity-and-platform-scope.md) - A macOS Retina comparison found polarity-dependent Chromium stroke coverage, so native-terminal calibration must control colours and remain scoped to the measured platform.
* [An idle child may be an undelivered wake](idle-child-may-be-an-undelivered-wake.md) - Check that a child moved after mailing it; a registration that never delivered clears by re-registering, not pause and resume.
