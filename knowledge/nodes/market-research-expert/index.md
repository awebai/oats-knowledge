# market-research-expert

Dated, attributable research about the landscape OATS lives in: fair, scoped
comparisons with provider-native subagent and workflow frameworks and other
agent-team approaches, and the positioning evidence behind claims OATS makes
about itself. The node holds only concepts with a date, a source and a stated
scope; an unknown is recorded as unknown, never filled in. Charter set by the
2026-09-13 rebuild decision
([Expert domains replace implementation job titles](/nodes/oats-expert/decisions/domain-expert-rebuild.md)),
which routes any comparison or positioning claim through this node before it
is promoted anywhere else in the base.

**This node is intentionally empty.** No legacy bundle held dated, attributable
market research (see the 2026-09-21 log entry); inventing seed concepts would
violate the OKF honesty rules and this charter. The first question it is
chartered to answer is the one currently asserted without evidence in
[Durable specialization](/nodes/oats-expert/decisions/durable-specialization.md):
how OATS's durable-specialist positioning compares with provider-native
subagent and workflow frameworks. Concepts appear here only when a
market-research-expert instance produces reviewed, dated, cited work.
