# Decisions

* [The human alias's host part is read from the deployment's local settings, not the hook environment, by one exported derivation](human-alias-host-comes-from-the-deployment-not-the-hook-environment.md) - The kernel's hook environment carries no host name, so the provider derives the human alias `<os-user>-<host>` by reading `host.name` from the deployment's `oats-local.yaml` with its own block-style reader, falling back to the short OS hostname, with the real OS user from `os.userInfo()`; one exported function serves the spawn brief and the later mint so a re-mint yields the same alias.
* [settings.oats.aweb.interaction is validated strictly, at spawn and at launch, before any aw call](interaction-setting-is-validated-strictly.md) - Absent means `terminal`; null, empty, non-string or unknown values are refused with a message naming the key, the received value and both accepted values, following the package's `claudeChannelMode` precedent rather than `delivery`'s silent coercion, because a mis-typed `threads` that silently became `terminal` would give Desktop no panel and the human no explanation.
* [Health receive evidence follows the delivery mode](receive-evidence-follows-delivery-mode.md) - The health publisher uses matching live and fresh native-stream receipts or fail-closed broker readiness according to delivery mode, because neither a leftover file nor a missing inapplicable receipt proves receive health.
* [A readiness cache needs measured publisher cost](readiness-cache-needs-measured-cost.md) - The health publisher deferred a readiness cache below an agreed approximate one-second per-home threshold, using bounded CLI CPU measurements and a remeasurement trigger rather than treating scratch timings as a production budget.
* [The scheduled publisher reuses the kernel job lock](publisher-reuses-scheduler-exclusion.md) - A second publisher tick lockfile was rejected because the kernel already serializes runs of the scheduled job and another lock would add a stale-lock failure mode.
